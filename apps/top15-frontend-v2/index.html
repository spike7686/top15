默认入口：末端转弱 > 结构止损 > 1R / 12h 管理

            

          

        


        

        

          
反向做空研究策略

          
只做交叉候选成立后的转弱段，主策略改为结构止损，不再用固定百分比止损做主模板。

        

        

        

              

                
主规则

                
    
                  
  • 先等当前 overlap_candidate = true，或最近 2h 内曾进入 overlap_candidate 后再做，不在第一次冲榜时提前埋伏。
    • 
                  
  • 基础转弱触发：trend_1h 转为 Range / Down / StrongDown，且 overlap_score_delta_30m <= 0。
    • 
                  
  • 标准开空还要额外满足 breakout_1h = NoBreakout，且 24h 涨幅位于 3% 到 8%。
    • 
                

              

          

            
信号分层

            
    
              
  • 观察：只满足交叉候选后的转弱，不满足过滤或结构止损窗口时只观察。
    • 
              
  • 标准开空：满足主规则 + 结构止损可交易，允许做模拟开空。
    • 
              
  • 高置信狙击：标准开空基础上，再叠加 OI 扩张、贴水加深等确认层。
    • 
            

          

              

                
模拟开空

                
    
                  
  • 默认单笔风险预算 5% 账户权益，默认总名义敞口上限 200%，结构止损 = 前高(2h) + 0.35 x ATR14(1h)。
    • 
                  
  • 止盈固定 1R，最长持有 12 小时；结构止损必须落在 0.8% 到 4.5% 的窗口内。
    • 
                  
  • 页面中的模拟仓位仅做研究与纸面跟踪，不连接交易所、不自动下单。
    •
