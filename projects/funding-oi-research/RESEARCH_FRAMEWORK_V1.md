# 资金费率 / 合约 OI 研究框架 V1

## 定位

这是一个与 TOP15 现货涨幅研究完全分离的独立研究工作区。

- 研究主题：资金费率（Funding Rate）/ 永续合约 / 未平仓量（OI, Open Interest）
- 研究目标：识别杠杆资金拥挤、趋势延续、反转挤压与爆仓驱动机会
- 与 TOP15 的边界：
  - TOP15 研究现货强势币与榜单轮动
  - 本工作区研究合约资金结构、拥挤度、杠杆风险与趋势驱动
  - 两者结论默认不互相引用，除非用户明确要求联动分析

---

## 关键术语

- 资金费率（Funding Rate）：永续合约中多空双方定期支付的费用，用于让合约价格贴近现货价格。
- OI（Open Interest，未平仓量）：当前市场中尚未平仓的合约总量，用于观察资金是否持续进出场。
- 多空拥挤：大量杠杆集中在同一方向，导致市场更容易出现挤仓或连锁平仓。
- Long Squeeze（多头挤压）：价格下跌导致多头集中止损/强平，进一步放大跌势。
- Short Squeeze（空头挤压）：价格上涨导致空头集中止损/强平，进一步放大涨势。

---

## 一、研究目标

本研究默认聚焦以下 4 类问题：

1. **趋势是否有杠杆资金在推动**
   - 价格上涨/下跌时，OI 是否同步扩张？
   - 资金费率是否在配合趋势加速？

2. **上涨/下跌是否健康，还是拥挤过度**
   - 高资金费率 + 高 OI 可能意味着多头过热
   - 极端负费率 + 高 OI 可能意味着空头拥挤

3. **反转是否可能由挤仓触发**
   - 不是单纯技术反转，而是杠杆仓位被动平仓引发的急变

4. **行情是“现货推动”还是“合约推动”**
   - 若价格走强但 OI 不跟，可能是现货主导
   - 若价格走强且 OI 快速扩张，通常说明合约资金正在参与甚至主导

## 二、核心观察指标

### 1. 价格
- 5m / 15m / 1h / 4h / 1d 涨跌幅
- 波动率
- 关键位突破 / 跌破

### 2. OI（未平仓量）
- OI 绝对值
- OI 变化率（5m / 1h / 4h / 24h）
- OI 斜率与加速度
- OI 与价格的同步/背离关系

### 3. 资金费率
- 当前资金费率
- 近几期资金费率均值
- 资金费率极值分位
- 资金费率变化速度

### 4. 成交与爆仓
- 主动买入 / 主动卖出强度
- 成交量放大程度
- 多头/空头爆仓规模
- 爆仓是否形成趋势放大器

### 5. 基差与结构信号（后续可扩展）
- 合约-现货价差（Basis）
- 多空比
- 大户持仓方向
- 交易所间 OI 分布差异

## 三、核心分析框架

### 场景 A：价格上涨 + OI 上升
**解释：** 新资金追多，趋势通常更有延续性，但也要警惕后期拥挤。

重点看：
- 资金费率是否持续抬升
- OI 增长是否过快
- 是否出现“涨得越快，费率越高”的过热状态

初步判断：
- 温和上涨 + OI 递增：偏健康趋势
- 急涨 + OI 暴增 + 高费率：偏拥挤，防 short-term 回撤

### 场景 B：价格上涨 + OI 下降
**解释：** 更像空头回补或空头挤压，不一定代表新多头趋势真的稳固。

重点看：
- 空头爆仓是否明显增加
- 资金费率是否同步上行
- 上涨后 OI 是否重新开始回补

初步判断：
- 若仅靠空头回补推动，行情持续性通常弱于“价格涨 + OI涨”

### 场景 C：价格下跌 + OI 上升
**解释：** 新空头在堆积，趋势可能延续，但也容易酝酿未来 short squeeze 的反面结构（即空头过度拥挤后的反抽）。

重点看：
- 资金费率是否转负并持续走低
- OI 上升是否伴随放量下跌
- 是否跌破关键结构位

初步判断：
- 若负费率扩大且 OI 增长稳定，通常说明空头主导增强

### 场景 D：价格下跌 + OI 下降
**解释：** 可能是多头止损/多头挤压，跌势未必代表新增空头强势入场。

重点看：
- 多头爆仓是否集中释放
- 跌后 OI 是否止跌
- 若 OI 快速出清后价格企稳，容易出现技术性反弹

## 四、重点风险识别模型

### 1. 多头过热风险
典型特征：
- 价格连续上涨
- OI 持续放大
- 资金费率显著偏正，且达到阶段高位

含义：
- 说明多头拥挤在累积
- 趋势未必立刻结束，但回撤和多头踩踏风险上升

### 2. 空头过热风险
典型特征：
- 价格持续下跌
- OI 上升
- 资金费率显著偏负

含义：
- 说明空头方向一致性很强
- 一旦现货买盘回流或利空钝化，容易触发 short squeeze

### 3. 假突破 / 假跌破
典型特征：
- 价格突破关键位，但 OI 没有配合扩张
- 或资金费率未能确认

含义：
- 趋势可信度不足
- 可能只是短线扫单，不是结构性趋势延伸
